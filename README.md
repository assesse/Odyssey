# Odyssey (할머니 길찾기)

고령 사용자를 위한 단순하고 직관적인 맞춤형 대중교통(버스·지하철) 길찾기 Android 애플리케이션입니다.

---

## 1. 앱 주요 특징

- **지도 비의존 텍스트 중심 UI**: 복잡한 지도 화면 대신 큰 글씨와 명확한 단계별 카드 안내를 제공합니다.
- **원터치 '집으로 가기'**: 현재 위치(GPS)에서 등록된 집까지 가장 환승이 적은 대중교통 경로를 즉시 안내합니다.
- **고정 목적지 빠른 길찾기**: 보호자가 사전에 등록한 최대 6개의 주요 목적지(병원, 시장, 복지관 등)로 원터치 길찾기를 지원합니다.
- **고령자 맞춤 경로 우선순위**: 소요 시간보다 **환승 횟수 최소화(0회 직통 최우선)** 및 **도보 거리 최소화** 경로를 최우선으로 추천합니다.
- **안전한 보호자 관리자 모드**: 상단 로고 5회 탭 및 4자리 PIN 인증을 통해 보호자가 안전하게 집 주소/좌표와 목적지를 관리합니다.

---

## 2. 개발 및 빌드 환경

- **JDK**: Java 17 (Eclipse Temurin 17 권장)
- **Android SDK**: Compile SDK 35, Min SDK 26 (Android 8.0 Oreo 이상), Target SDK 35
- **UI Framework**: Jetpack Compose + Material 3
- **Network & Data**: Retrofit 2, OkHttp 4, Gson, Play Services Location

---

## 3. ODsay API Key 설정

이 앱은 [ODsay 대중교통 길찾기 API v1.8](https://lab.odsay.com/)을 활용합니다.

1. 프로젝트 루트 디렉터리에 `local.properties` 파일을 생성하거나 수정합니다.
2. 발급받은 ODsay API Key를 입력합니다:
   ```properties
   ODSAY_API_KEY=your_actual_odsay_api_key_here
   ```
3. `local.properties` 파일은 `.gitignore`에 등록되어 있어 Git 저장소에 커밋되지 않습니다.

> [!WARNING]
> 모바일 클라이언트 앱에 포함되는 API Key는 역컴파일 등을 통해 추출될 위험이 있으므로, 상용 서비스 배포 시에는 백엔드 프록시 서버 도입을 권장합니다.

---

## 4. 보호자 관리자 설정 및 이용 방법

1. **관리자 진입**: 홈 화면 상단의 `🚌 할머니 길찾기` 로고를 **5회 연속으로 빠르게 탭**합니다.
2. **PIN 인증**: 기본 PIN `1234`를 입력하여 관리자 화면으로 진입합니다. (관리자 화면에서 새 4자리 PIN으로 변경 가능)
3. **집 위치 등록**: 보호자가 어르신의 실제 집 위도/경도 및 주소를 입력하고 저장합니다.
4. **목적지 관리**:
   - 병원, 복지관, 시장 등 최대 6개의 고정 목적지 추가.
   - 명칭, 표시 이름, 위도, 경도, 순서(위/아래 이동), 수정, 삭제 지원.
5. **설정 완료 후**: 홈 화면으로 복귀 시 등록된 목적지 버튼이 즉시 화면에 갱신됩니다.

## 6. 실기기 수동 검증 체크리스트

1. **신규 설치 및 초기 실행**:
   - [ ] 앱 최초 실행 시 "등록된 목적지가 없어요" 안내 표시 확인.
   - [ ] 상단 로고 5회 탭으로 PIN 입력 화면 정상 전환 확인.
2. **보호자 설정**:
   - [ ] 초기 PIN(`1234`) 입력 후 관리자 화면 진입 확인.
   - [ ] 유효한 집 좌표(위도 `37.xxx`, 경도 `126.xxx` 또는 `127.xxx`) 저장 확인.
   - [ ] 목적지 1개 이상 추가 후 홈 화면에서 즉시 버튼 노출 확인.
3. **일반 목적지 길찾기**:
   - [ ] 목적지 버튼 탭 → 확인 화면("OO으로 갈까요?") 노출 확인.
   - [ ] "네" 선택 시 **위치 권한 요청 없이** 집 → 목적지 경로가 정확히 표시되는지 확인.
4. **'집으로 가기' (위치 권한 & GPS)**:
   - [ ] "집으로 가기" 탭 시 위치 권한 요청 팝업 정상 노출 확인.
   - [ ] 권한 허용 후 현재 위치 → 집 경로 정상 안내 확인.
   - [ ] GPS 비활성화 상태에서 "위치 설정 열기" 안내 버튼 및 복구 확인.
5. **고령자 접근성 & 레이아웃**:
   - [ ] 안드로이드 시스템 설정에서 글자 크기를 '매우 큼'으로 설정해도 버튼이나 텍스트가 잘리지 않고 스크롤되는지 확인.
   - [ ] 360dp 너비의 작은 단말기에서도 모든 버튼과 카드가 정상 스크롤되는지 확인.
